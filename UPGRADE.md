# Доработка и доказательства готовности

Дата: 2026-10-09.

## Реализовано

Выбор конкретного кадра DICOM, проверка размеров до декодирования и декодирование одного кадра. Проверка vision-capability Ollama. Системные правила отделены от данных врача; ответ проверяется по обязательным полям и размеру. Протокол сохраняет имя/хеш модели, время, выбранные кадры и SHA-256 PNG; статус клинической валидации явно false. Исправлено отображение ошибок загрузки.

## Аналог и применённый подход

[MedSAM](https://github.com/bowang-lab/MedSAM) и [LLaVA-Med](https://github.com/microsoft/LLaVA-Med)

Разделение задач медицинского изображения и проверяемого черновика. Эти модели не установлены: MedSAM сегментирует по подсказке, это не модель заключений, а наличие medical VLM не подтверждает пригодность для УЗИ.

## Запуск и проверка

```bash
pip install -r requirements.txt
python -m unittest -v
python server.py
# Открыть http://127.0.0.1:8765
```

Регрессионные тесты: `python -m pytest -q`. Локальная среда проверки: Windows, Python 3.12. CI проверяет отдельную чистую среду.

## Что требуется для оценки 10/10

Нужны обезличенный набор УЗИ по конкретному органу, сопоставленные протоколы и независимая проверка узистами. Инференс реальной vision-модели и клиническая точность здесь не проверены. Статичные кадры не заменяют динамическое исследование. Ограничение декодирования DICOM 128 МБ суммарно; большие серии нужно экспортировать выбранными кадрами. Персональные надписи в пикселях не удаляются автоматически.

Инженерные тесты подтверждают поведение кода; они не измеряют клиническую, гидрологическую или коммерческую точность. Метрики на синтетике нельзя переносить на реальные данные. Оценка 10/10 сейчас не заявляется.
