# Изменения

## 1.0.0 · 2026-10-12

- Устанавливаемая Windows-версия с собственным окном, встроенной средой Python и завершением локального сервера при закрытии.
- Сохранение русскоязычного многостраничного PDF и открытие ранее сохранённого JSON с повторной проверкой врачом.
- Настройка Ollama и явная загрузка локальной vision-модели с отображением прогресса.
- Проверка локальности модели; запрет перенаправлений и системных прокси для запросов с изображениями.
- Поддержка случайного локального порта, проверка Host/Origin и токена API, защита от одновременных запросов анализа.
- Обработка незавершённых ответов ИИ, ограничений размера, закрытия с несохранёнными изменениями и ошибок загрузки файлов.
- Дополнительные декодеры сжатых DICOM, включая JPEG-LS и JPEG 2000.

Клиническая валидация модели не проводилась. Номер версии относится к приложению.
