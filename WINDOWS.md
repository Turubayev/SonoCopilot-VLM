# SonoCopilot для Windows · 1.0.0

Приложение для подготовки и проверки протокола УЗИ. Установочный пакет включает Python, собственное окно, декодеры изображений и экспорт PDF. Отдельно устанавливать Python, браузер или инструменты разработчика не требуется.

Поддерживаемая платформа: Windows 10 22H2 / Windows 11, x64.

## Установка и первый запуск

1. Запустите `SonoCopilot-Setup-1.0.0.exe` и пройдите мастер установки. Установка выполняется для текущего пользователя.
2. Откройте SonoCopilot из меню «Пуск» или через созданный ярлык.
3. Добавьте PNG/JPEG/DICOM снимки. Для много кадрового DICOM укажите индекс нужного кадра, начиная с 0. Всего можно добавить до 6 снимков, до 20 МБ каждый. Совокупный запрос анализа ограничен 32 МБ, включая кодирование файлов.
4. Введите контекст и наблюдения. Кнопка составления по данным врача работает без подключения ИИ.
5. Отредактируйте описание и заключение, укажите врача и подтвердите проверку. Сохраните JSON для последующего редактирования или PDF для печати.

Файл JSON содержит текст протокола и сведения о происхождении, но не исходные изображения. После открытия JSON подтверждение врача сбрасывается: снимки нужно загрузить и проверить повторно. Закрытие с несохранёнными изменениями требует подтверждения.

## Подключение локального ИИ

1. В разделе «Подключить ИИ» откройте официальный установщик [Ollama для Windows](https://ollama.com/download/windows). Установите и запустите Ollama.
2. Вернитесь в SonoCopilot и обновите подключение.
3. Нажмите загрузку `gemma3:4b`. Это отдельная загрузка весов примерно 3,4 ГБ; потребуются интернет и свободное место. Дождитесь завершения. Можно также установить другую совместимую локальную vision-модель средствами Ollama.
4. Выберите модель, проверьте отсутствие персональных надписей в пикселях снимков и создайте черновик.

Ollama и веса не входят в установщик SonoCopilot. Размер весов не равен необходимой оперативной памяти: потребление зависит от модели, числа снимков и контекста. На компьютере без подходящего ускорителя анализ может занять несколько минут. Программа сообщает об отсутствии модели или превышении времени ожидания. Совместимость конкретного оборудования проверяется отдельно.

Модель `gemma3:4b` — общий мультимодальный вариант для технического подключения, а не проверенная модель для УЗИ. SonoCopilot проверяет заявленную поддержку изображений и отклоняет модели, помеченные как облачные. Изображения направляются только на `127.0.0.1:11434`; автоматическое скачивание модели не отправляет снимки. Обслуживание локального Ollama и его настройки остаются под контролем пользователя.

Документация: [Ollama Windows](https://docs.ollama.com/windows), [обработка изображений](https://docs.ollama.com/capabilities/vision), [Gemma 3 и условия модели](https://ollama.com/library/gemma3).

## Данные и ограничения

Исследования находятся в памяти приложения до сохранения. Автоматического архива пациентов нет. Снимки в PDF/JSON не включаются. Сохранённые вами файлы остаются на диске после закрытия и удаления приложения. Приложение не сохраняет введённые данные в диагностические логи. Окно использует временный профиль, без постоянной истории браузера.

DICOM-теги пациента не передаются модели. ФИО и другие надписи внутри пикселей автоматически не удаляются. Для сжатых DICOM включены JPEG/JPEG-LS/JPEG 2000 декодеры, однако поддержка зависит от конкретного формата; при несовместимости используйте экспорт PNG/JPEG с аппарата. Видеопетля целиком не анализируется: используется выбранный кадр.

Это устанавливаемое исследовательское приложение, клиническая точность которого не подтверждена. Оно не выполняет автоматические измерения и не заменяет заключение врача. Подтверждение протокола не является электронной подписью.

## Удаление и обновление

Для удаления используйте «Параметры Windows → Приложения → Установленные приложения → SonoCopilot». Ollama удаляется отдельно. Экспортированные протоколы и отдельно установленные веса не удаляются вместе с SonoCopilot.

Для обновления сначала сохраните протокол и закройте SonoCopilot, затем запустите новый установщик. Автоматического обновления по сети нет.

## Сборка из исходников

Инструкции и параметры воспроизводимой сборки находятся в `packaging/`. Зависимости компонентов сопровождаются уведомлениями об их лицензиях. У этой сборки нет коммерческой цифровой подписи издателя.
