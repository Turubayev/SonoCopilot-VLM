# SonoCopilot — локальное рабочее место врача УЗИ

Рабочий исследовательский прототип, созданный по описанию sonocopilot_vlm_readme.md. Исходного репозитория и весов в переданном файле не было. Это приложение не является валидированной диагностической системой.

## Запуск в Windows

В PowerShell откройте эту папку и выполните `powershell -ExecutionPolicy Bypass -File .\start.ps1`. Скрипт использует Python из среды Codex, если он доступен, иначе установленный `python`. Откройте http://127.0.0.1:8765. Если порт занят уже запущенной версией, используйте существующее окно приложения. Для остановки сервера нажмите Ctrl+C в окне запуска.

На другом компьютере: Python 3.10+, `python -m pip install -r requirements.txt`, затем `python server.py`.

## Реальный анализ с ИИ

Установите и запустите [Ollama](https://ollama.com). Установите совместимую модель с поддержкой изображений по [официальной документации](https://docs.ollama.com/capabilities/vision). В приложении нажмите «Обновить» и выберите установленную модель. Модели и веса не включены, автоматически не скачиваются; требования к памяти зависят от модели. Проверка ответа конкретной медицинской модели и клиническая валидация не выполнены.

Подключение фиксировано: http://127.0.0.1:11434. Снимки отправляются только локальному серверу Ollama. Общие мультимодальные модели могут ошибаться и не подтверждают диагностическую точность. Без Ollama можно составить протокол по введенным наблюдениям врача; это явно обозначается в протоколе.

## Что реализовано

- Загрузка до 6 PNG/JPEG/DICOM файлов, просмотр и удаление снимков.
- Декодирование DICOM US и преобразование в PNG без исходных метаданных пациента. Для много кадров отображается и анализируется только первый кадр. Сжатые DICOM могут требовать дополнительных декодеров pydicom.
- Возраст, показания, измерения и наблюдения врача.
- Интеграция с Ollama, структурированный ответ, обработка отсутствующей модели и некорректных ответов.
- Редактирование, подтверждение врачом, сброс подтверждения после изменений.
- Экспорт JSON и полноценная печатная форма (в диалоге печати выберите сохранение в PDF).
- Сервер доступен только на loopback; проверка Host и токена запросов; данные не записываются на диск и не логируются приложением.

## Ограничения

Надписи с ФИО в пикселях автоматически не удаляются: перед анализом нужен ручной контроль. Автоматической сегментации MedSAM, локализации патологий, анализа видеопетель и расчета TI-RADS/BI-RADS/LI-RADS нет. Измерения вводит врач; приложение не измеряет структуры по пикселям. Нет PACS, учетных записей, журнала клинических изменений и юридической электронной подписи. Подтверждение — отметка в текущем протоколе, а не проверенная идентификация врача. Не заявляется соответствие HIPAA/GDPR. За настройки и хранение данных локальным сервером модели отвечает его оператор. Экспортированные файлы необходимо хранить согласно правилам клиники.

## Проверки

`python -m unittest -v test_server.py` — изображения, поврежденные файлы, синтетический DICOM, исключение тегов пациента, обязательный контроль приватности и контракт ответа модели. В тестах VLM подменяется: они не доказывают качество медицинского анализа. `node --check app.js` — синтаксис JavaScript.
