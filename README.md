# SonoCopilot-VLM · 1.0.0

Локальное рабочее место врача УЗИ для Windows: загрузка снимков, подготовка черновика протокола с локальной моделью или по данным врача, редактирование, проверка и сохранение.

**Устанавливаемая версия:** `SonoCopilot-Setup-1.0.0.exe`. Python и компоненты окна входят в пакет. Инструкция пользователя, подключение ИИ и ограничения: [WINDOWS.md](WINDOWS.md).

Версия приложения не означает клиническую валидацию. Диагностическая точность модели на УЗИ не подтверждена; итоговое содержание проверяет врач.

## Возможности

- Отдельное окно Windows, установка для текущего пользователя и удаление через список приложений.
- До 6 PNG/JPEG/DICOM снимков; для DICOM US явно выбирается кадр. Лимит 20 МБ на файл и 32 МБ на запрос анализа.
- Декодирование DICOM, включая дополнительные JPEG/JPEG-LS/JPEG 2000 плагины. Поддержка конкретного синтаксиса зависит от декодера.
- Контекст, измерения и наблюдения врача; ручное составление доступно без модели и интернета.
- Интеграция с локальным Ollama: проверка поддержки изображений, отклонение облачных моделей и загрузка gemma3:4b по явному действию пользователя.
- Редактируемый черновик, сведения о модели и выбранных кадрах, сброс подтверждения при изменениях.
- Сохранение JSON, повторное открытие JSON с новым подтверждением, многостраничный PDF с русским текстом.
- Предупреждение о несохранённых изменениях при закрытии; локальный сервер прекращает работу вместе с окном.

## Локальная модель

[Ollama](https://ollama.com/download/windows) и веса устанавливаются отдельно. Для первого подключения есть встроенная инструкция и загрузка gemma3:4b (примерно 3,4 ГБ). Это общая мультимодальная модель для проверки интеграции, а не проверенная медицинская модель.

Подключение фиксировано на http://127.0.0.1:11434. Запросы с изображениями не используют системный прокси и не следуют HTTP-перенаправлениям. Требования к памяти и скорость зависят от модели и оборудования. После установки локальной модели обработка не требует интернет-подключения, если сам Ollama настроен на локальное выполнение.

Официальные сведения: [Windows](https://docs.ollama.com/windows), [Vision API](https://docs.ollama.com/capabilities/vision), [Gemma 3](https://ollama.com/library/gemma3).

## Данные

Исследование хранится в памяти окна до явного сохранения пользователем. Постоянная история браузера отключена. PDF и JSON содержат текст, но не сами снимки. Исходные DICOM-теги пациента не передаются модели; надписи в пикселях автоматически не удаляются. Приложение не ведёт журналов содержимого снимков или протоколов.

Не реализованы PACS, автоматические измерения по пикселям, анализ всей видеопетли, электронная подпись и автоматические TI-RADS/BI-RADS/LI-RADS. Общая vision-модель может ошибаться и придумывать находки. Подтверждение протокола — отметка пользователя, а не подтверждённая идентификация врача.

## Запуск исходного кода

Python 3.11/3.12:

```powershell
python -m pip install -r requirements.txt
python server.py
```

Откройте http://127.0.0.1:8765. Для отдельного окна установите requirements-desktop.txt и запустите python desktop.py. При запуске desktop используется свободный порт автоматически.

## Проверка и сборка

```powershell
python -m pip install -r requirements.txt pytest pypdf
python -m pytest -q
node --check app.js
node --test test_frontend.cjs
```

В тестах ответы модели подменяются. Они проверяют обработку файлов, API, происхождение протокола и ошибки, но не клиническую точность. Команды сборки находятся в packaging/build.ps1. Сборка Windows использует PyInstaller и Inno Setup. Компоненты сопровождаются [уведомлениями о лицензиях](THIRD_PARTY_NOTICES.md).
